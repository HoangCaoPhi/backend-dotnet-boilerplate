# Doc / Explanation Style

- Short, bullet the main points — avoid long-winded writing, avoid rambling explanatory paragraphs.

## Writing `.claude/rules/*.md` files

- Include: decisions, rationale, conventions differing from defaults, pitfalls.
- Exclude: file/folder listings — once real code exists, read it instead.
- Detailed folder spec for unbuilt parts → `temp/`, not a rule.
